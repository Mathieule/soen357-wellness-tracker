# Archive – version 1 (faithful to Task 3)

First implementation of Output A and Output B, built to reproduce the Task 3
specification literally, plus an early Output C visual preview. Kept unchanged
for traceability (git tag `v1-task3-faithful`).

It was superseded by the full UI/UX redesign (see the root README): the new
Output A, B and C share one design system and a personalization engine.

Run the archived apps from the project root:

```bash
npm run archive:a   # http://localhost:5181
npm run archive:b   # http://localhost:5182
```

Lo-fi boards: `Output_A/lo-fi/index.html`, `Output_B/lo-fi/index.html`.
Hi-fi galleries: `Output_A/hi-fi/index.html`, `Output_B/hi-fi/index.html`.
